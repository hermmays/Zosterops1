Distance trees, PCA, UMAP, and DAPC analyses

Goals

What follows is an analysis of the Zosterops single nucleotide polymorphism (SNP) data from our double digest restriction-site associated DNA (ddRAD) library or RADseq. This analysis seeks to describe general metrics of diversity and variation in East Asian Zosterops and makes some attempt to assess the utility of these data in clustering individuals by putative taxonomic and population groups.

Getting started

We are using R version 4.4.2, RStudio version 2024.09.1 for the analysis. Quarto version 1.6.39 for Mac OS was used to document the workflow. Set the working directory in RStudio to one where the vcf.gz zipped data file and a txt file denoting the identity of the samples are accessible.

General methods summary

RADseq-derived SNP dataset

The RADseq-derived SNP dataset in this study was previously analyzed in DeRaad et al. (D. A. DeRaad et al. 2024), which includes detailed methodological description. Briefly, restriction site associated DNA libraries were constructed by digesting gDNA using the enzyme NdeI and performing size selection for fragments between 495 – 605 base-pairs (bp). The complete library preparation protocol is available at https://github.com/DevonDeRaad/zosterops.rad/blob/main/lab.protocols/MSG-NdeI_2plates-150samples_DAD-Moyle_230530.doc. Pooled, bar-coded libraries were sequenced on the Illumina NextSeq2000 at the University of Kansas Genomic Sequencing Core using a P2 flow cell to generate 414,215,817 single-end 100 bp reads (approximately 41Gb raw sequence data). Raw genomic sequencing data is publicly available via the SRA BioProject PRJNA1079333 (https://www.ncbi.nlm.nih.gov/sra/PRJNA1079333).

Read mapping, variant calls, and filtering

Mapping, variant calling, and filtering was performed as in DeRaad et al. (2023) and DeRaad et al. (2024) (D. A. DeRaad et al. 2023, 2024). Raw data was demultiplexed and reads of low quality and with uncalled bases were removed using Stacks v2.41 (Rochette, Rivera-Colón, and Catchen 2019). Reads were then mapped to a publicly available Z. japonicus genome assembly available at https://www.ncbi.nlm.nih.gov/assembly/GCA_017612475.1 (Venkatraman, Fleischer, and Tsuchiya 2021) using the Burrows-Wheeler Alignment tool (BWA) v0.7.17 (Li and Durbin 2009). SAMtools v1.3.1 (Li et al. 2009) was used to convert files to a sorted bam format and RAD loci were identified in Stacks using the ‘gstacks’ module and exported as a variant call format (VCF) file resulting in an unfiltered SNP dataset containing 236,767 SNPs shared among 155 individual samples with 65.5% missing genotypes. The R packages vcfR v1.14.0 (Knaus and Grünwald 2017) and SNPfiltR v1.0.1 (D. DeRaad 2023) were used to visualize parameter distributions and filter the SNP data for quality. The final filtered VCF file included 15,704 SNPs across 124 individual samples with 5.3% missing data. A more detailed description of the filtering protocol may be found in DeRaad et al. (D. A. DeRaad et al. 2024) and at: https://devonderaad.github.io/zosterops.rad/zost.radseq.filtering.html.

A pairwise distance matrix based on Nei’s D (Nei 1972) was generated from the filtered SNP dataset using the R package StAMPP v1.6.3 (Pembleton, Cogan, and Forster 2013) and used to construct a neighbor-net phylogenetic network using the R package SplitsTree4 v4.15.1 (Huson and Bryant 2005). This allowed us to visualize the data and, in some cases, validate the identity of individual samples for subsequent analyses. For example, the sample designated Zsim30897 was initially identified as Z. simplex, and given an identification code to match, however in a phylogenetic network this sample clustered with the very divergent Z. palpebrosus and was therefore revised to match that identity. Associated R code and the phylogenetic network from SplitsTree v4.15.1 are described in DeRaad et al. (D. A. DeRaad et al. 2024) and may be viewed at https://devonderaad.github.io/zosterops.rad/splitstree.html.

General SNP visualization and multivariate analyses

Various approaches were employed to visualize variation in the SNP dataset. The filtered SNP VCF file was converted to a genlight object for subsequent analyses using the ‘vcfR2genlight’ command in the R package vcfR (Knaus and Grünwald 2017). The R package Poppr (Kamvar, Tabima, and Grünwald 2014) was used to generate a minimum spanning network (MSN) and a distance tree based on the unweighted pair group method (UPGMA). Bootstrapping was performed for the UPGMA tree with 100 replicates.

A principal component analysis (PCA) and a discriminant function analysis of principal components (DAPC) was conducted using the R package adegenet (T. Jombart 2008) following the methodology from Jombart et al. (Thibaut Jombart, Devillard, and Balloux 2010). DAPC is a multivariate method that takes principal components (PCs) and partitions variance into within- and among-group components in a way that maximizes discrimination among the groups. DAPC makes no explicit assumptions regarding recombination or panmixia. This allows use of the full SNP dataset without additional filtering to reduce the likelihood of linkage as is required for other clustering analyses such as Structure (Pritchard, Stephens, and Donnelly 2000; Porras-Hurtado et al. 2013) or Admixture (Alexander, Novembre, and Lange 2009).

The DAPC analysis was conducted in R and based from a tutorial available at https://grunwaldlab.github.io/Population_Genetics_in_R/DAPC.html. Samples were grouped by a combination of species, subspecies, and geography with Z. japonicus split into the most far-flung Z. japonicus alani subspecies in the Ogasawara and Volcano Islands and a broader Z. japonicus group encompassing the remaining subspecies. Z. montanus samples were grouped into a Northern Philippine group including Z. montanus whiteheadi on Luzon and Z. montanus halconensis on Mindoro, Z. montanus parkesi on Palawan, and a southern group including the remaining Z. montanus subspecies from the Visayas, Camiguin South, Mindanao, Sulawesi, and Java. The remaining samples were assigned to groups based on their species.

PCA was conducted on the filtered SNP dataset (15,704 SNPs, 124 individual samples) using the sample groups described above. PCs were generated using the ‘glPca’ function in adegenet (T. Jombart 2008). We generated plots in two dimensions (PCs 1-2) and in three dimensions (PCs 1-3) using the R package plotly (Sievert 2020).  

We conducted a cross-validation analysis to help determine the optimal number of PCs to be retained in the DAPC by examining the proportion of successful assignments for each PC for the first 50 PCs and 100 replicate runs per PC. This analysis showed that successful assignments greatly increased from PC1 to PC13 and leveled off until declining at approximately PC30. We also estimated the difference between the proportion of successful reassignments using the real groups and assignments of individual samples into randomly assigned groups (i.e. the a-score). The mean a-score across replicate runs therefore estimates the average percent improvement in discrimination over that based on random groupings. We used the ‘dapc’ function in adegenet to estimate the mean a-score across 30 replicate runs and for each of the first 40 PCs. This process was repeated 100 times generating an optimization graph for each run. The median optimal number of PCs was calculated from these 100 runs and used in the subsequent DAPC analysis. The DAPC analysis was conducted based on the optimal number of PCs, determined as described above, in which we estimated the posterior membership probability for each individual sample. We conducted two additional DAPC analyses based on 50% fewer and 50% greater than the optimal number of PCs.

In addition to PCA we conducted a second dimensionality reduction on the SNP data using the uniform manifold approximation and projection (UMAP) method (“Uniform Manifold Approximation and Projection” 2024). Analysis via both methods allowed for the visualization of the SNP data by a linear method emphasizing variation (PCA) and a non-linear method emphasizing global structure among groups (UMAP). UMAP was performed with the ‘umap’ function in the R package umap (Konopka 2023) and plots generated in two and three dimensions using the R package plotly (Sievert 2020).

Calculate the centroids for each group based on the first three principal components and the pairwise Euclidean distances between each pair of groups.

Zosterops_PCAscores <- ZosteropsSNPsPCA$scores[, 1:3]
Zosterops_PCAgroups <- gl.ZosteropsSNPs@pop
Zosterops_PCAdf <- data.frame(Zosterops_PCAscores, Group = Zosterops_PCAgroups)
Zosterops_unique_PCAgroups <- unique(Zosterops_PCAgroups)
Zosterops_PCAcentroids <- data.frame(Group = character(), PC1 = numeric(), PC2 = numeric(), PC3 = numeric(), PC4 = numeric(), PC5 = numeric(), stringsAsFactors = FALSE)
# Loop through each unique group to calculate centroids
for (group in Zosterops_unique_PCAgroups) {
  group_scores <- Zosterops_PCAdf[Zosterops_PCAdf$Group == group, 1:3]
  centroid <- colMeans(group_scores, na.rm = TRUE)
  Zosterops_PCAcentroids <- rbind(Zosterops_PCAcentroids, 
                                   data.frame(Group = group, 
                                              PC1 = centroid[1], 
                                              PC2 = centroid[2], 
                                              PC3 = centroid[3]))

Uniform manifold approximation and projection (UMAP)

Uniform manifold approximation and projection (UMAP) (“Uniform Manifold Approximation and Projection” 2024) is a non-linear, stochastic algorithm to reduce dimensionality for visualization of multivariate data. UMAP seeks to preserve as much of the relationships among groups in the dataset as possible while reducing to a minimal number of components. In this case we are visualizing the SNP data with UMAP for two and three dimensions using the umap package and plotting the results for each analysis using the plot_ly command from the plotly package. The n_neighbors, min_dist, and metric arguments all reflect the default values. For each plot save as html files using the saveWidget command in the htmlwidgets package.

Discriminant analysis of principal components (DAPC)

DAPC cross-validation, a-scores, and optimal number of PCs for discrimination

Discriminant analysis of principal components (DAPC) is a multivariate method that takes principal components (PCs) and partitions variance into within- and among-group components in a way that maximizes discrimination among the groups (Thibaut Jombart, Devillard, and Balloux 2010). DAPC makes no explicit assumptions regarding recombination or panmixia. This allows use of the full SNP dataset without worrying about filtering to reduce the likelihood of linkage as is required for STRUCTURE or ADMIXTURE. A tutorial on DAPC is available here. First conduct a cross-validation analysis to help determine the optimal number of PCs to be retained in the DAPC. Test between 1 and 50 PCs (n.pca = 1:50) with 100 replicate runs per PC (n.rep = 100) of the cross-validation analysis. Use the multicore option and 6 CPUs (ncpus = 6L), or potentially more if your machine allows it. Even running multiple cores this run can take a while to execute. Executing this analysis within the system.time command will return an elapsed time for the operation. This will return a graph showing the proportion of successful group predictions on the y-axis and the results from the individual replicate runs for each PC on the x-axis.

a-scores

The DAPC cross validation provides some clues as to where we no longer need to add PCs to the DAPC to get increased discrimination, but we want to know exactly how many PCs is optimum for discrimination. The a-score is the difference between the proportion of successful reassignments using the real groups and assignments into randomly assigned groups. Thus the average a-score is the average percent improvement in discrimination over that based on random groupings. The code below will estimate the a-score across 30 replicate runs (n.sim = 30) and 40 PCs (n.pca = 40) showing the result per group for each run, the average across all replicates per group, and the overall average.
