Extra code showing how to add branch support using ape

Don’t add this to the yml fie and index. It is just saving some extra code for possible use later.

This is an ancillary bit of code showing how to use ape to add branch support values to a tree. It is pretty tedious. There must be a better way to do this. Surely ape can read support values from a newick formatted tree?

Likely can use this code to make a nicer looking tree that could be used as a figure in the manuscript?

This example is from the *BEAST2 consensus species tree from the A runs series of 20 replicate runs using all loci and the Zosterops taxon sets A.txt taxon set file. Tree edited in FigTree with posterior probability displayed at the nodes and an axis in Ma.
